# Provenance

Milim Player is a clean-room, Milim-owned implementation developed for Gaia
Research. This public repository was extracted from the private Milim
pipeline's frozen Sol player commit
`f429da50abf3df3bb9079eb2b6f57ad9b7694fcd`. That identifier records the fixed
extraction source; it is not a self-reference to a commit in this repository.

The implementation contains no Stretchy or Cubism source code and no Milim
character or scene assets. It has no production dependency on Stretchy,
Cubism, Rive, or Spine.

The Apache License 2.0 applies to the runtime source and public documentation in
this repository. It does not license Milim character art, model or scene packs,
Gaia Research branding, or private production-pipeline materials.
