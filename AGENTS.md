# Milim Player agent contract

Cache with `CLAUDE.md` if one is added later.

## Ownership

Sol owns the public player API, renderer, lifecycle, validation, and player
tests. The private `gaia-research/milim` repository owns source art, models,
scenes, Milim Studio, compiler, release assembly, and production evidence.

Do not add editable character assets, private repository URLs, credentials, or
unpublished production artifacts. The first release has zero third-party
production dependencies: do not add package dependencies, remote runtime
imports, Cubism, Stretchy, Rive, or Spine.

All changes to `main` use pull requests and the GitHub Free-compatible controls
documented in `.github/BRANCH_PROTECTION.md`.
